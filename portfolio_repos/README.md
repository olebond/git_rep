# Portfolio Project Candidates

This directory contains cleaned-up project candidates extracted from the original learning workspace.

The goal is to turn a mixed study repository into several focused repositories that are easier to understand during job applications and interviews.

## Projects

| Folder | Project | Main Focus |
| --- | --- | --- |
| `01-databricks-flight-lakehouse` | Databricks Flight Lakehouse | Azure, Databricks, Delta Lake, Bronze/Silver pipelines |
| `02-python-flight-data-converter` | Python Flight Data Converter | Python CLI, CSV transformation, tests |
| `03-spark-batch-data-quality` | Spark Batch Data Quality | PySpark validation and schema checks |
| `04-airflow-file-pipeline` | Airflow File Pipeline | Airflow DAG and Docker Compose |

Each folder is intended to become a separate public GitHub repository after review and cleanup.
